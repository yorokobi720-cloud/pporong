# 뽀롱 (pporong)

아티스트(아이돌)와 팬이 소통하는 앱. 프롬·위버스 스타일, 초등 고학년 대상.

## 두 가지 입장
| | 팬 | 아티스트 |
|---|---|---|
| 입장 | 닉네임만 입력 | 아티스트 선택 + 비밀번호 |
| 하단 탭 | 홈 · 메시지 · 놀이터 · 마이 | 내 페이지 · 메시지 · 팬 · 설정 |

## 아티스트 페이지 (위버스 스타일)
- 전체 배경화면 + 프로필 사진: 휴대폰 갤러리에서 골라 바꾸기
- 탭: **아티스트**(피드) · **팬**(팬 게시판) · **미디어**(사진 모아보기) · **공지**(공지 / 🔴 라이브 알림)
- 글에 좋아요 ♥, 댓글 (아티스트 댓글은 강조 표시)
- 팬은 **멤버십 가입** 후 1:1 메시지, 편지, 팬 게시판 글쓰기 가능

## 메시지 (프롬 스타일)
- 아티스트 → 모든 팬 또는 특정 팬에게: 글·사진·영상·음성·편지, 예약 전송
- 팬 → 아티스트: 답장은 아티스트만 볼 수 있어요
- 말풍선 꾹 누르기 / 두 번 톡 → 하트 등 반응 (아티스트는 반응 개수 확인)
- 자동 답장, 반복 메시지(매일 아침 인사 등), 기념일 카드, 팬 생일 축하 카드, 가입 환영 메시지
- 아티스트가 팬에게 **칭찬 하트 선물**

## 놀이터 (팬)
출석 도장판, 하트 포인트, 스티커 상점, 아티스트 앨범, 편지 꾸미기(스티커·글자색)

## 파일
- `index.html`, `style.css`, `app.js` — 화면
- `store.js` — 저장소 (체험 모드: 이 기기 / 온라인 모드: Supabase)
- `config.js` — 온라인 연결 설정, 아티스트 등록 코드
- `supabase.sql`, `SETUP.md` — 온라인 연결 방법
- `v1-backup/` — 이전 버전(혼자 노는 버전)

## 실행 (PC 미리보기)
```powershell
python -m http.server 5173
```
→ http://localhost:5173 (체험 모드 데모 아티스트 **뽀롱이**, 비밀번호 **1234**)

체험 모드에서는 같은 PC의 브라우저 탭 두 개로 아티스트와 팬을 동시에 띄워 소통을 시험해 볼 수 있어요.
